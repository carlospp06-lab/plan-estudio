# Plan de Estudio

Web instalable (PWA) que reparte las horas de estudio de cada día según la fecha de los exámenes, el temario, la dificultad y la prioridad. Funciona sin conexión.

- Los datos se guardan en el propio dispositivo y se conservan al actualizar la app.
- Para publicar una versión nueva, sube `APP_VERSION` en `index.html` y `VERSION` en `sw.js`.
